# Readme_HUD.md - HUDスクリプトファイル

対象ファイル: `assets/<namespace>/hud/<名前>.txt`(独自のテキスト形式、MCヘリ本来の
HUDスクリプトに準拠した書式)

搭乗中の車両の画面に描画するカスタムHUD(照準・計器類・砲塔インジケーター等)を、
このテキストスクリプトで定義します。1つの`.txt`ファイルが1つの「スクリプト」に
対応し、車両側の設定でどのHUDスクリプトを使うか指定します(車両設定ファイル側の
HUD関連項目については`Readme_Vehicle.md`参照)。

## 1. ファイルの基本構造

### 基本書式

各行は`ディレクティブ = 引数1, 引数2, ...`という形式です(MCヘリ本来のHUD
スクリプト書式に準拠)。引数を取らないディレクティブ(`Exit`・`EndIf`)は
`=`なしでそのまま記述します。

```
DrawString = 0, 0, "Speed: %.0f", speed
```

- 行頭からの空白は無視されます。
- `;`以降はコメントとして無視されます(ダブルクォート文字列の内側を除く)。
- 空行は無視されます。
- 不正な行は、そのファイル全体を失敗させず、その1行だけがスキップされます
  (ログに警告が出力されます)。

### 条件分岐(`If` / `EndIf`)

```
If = hp_rto < 0.3
  Color = 255, 255, 0, 0
  DrawString = 0, -20, "WARNING"
EndIf
```

条件式(`If =`の右辺)は、後述の式構文で記述します。値が0以外であれば真として
扱われます。

- `If`から次の`EndIf`までが1つのブロックになります。`EndIf`を書き忘れると、
  **ファイルの最後までがその`If`の中**として扱われます。
- `If`のネスト(`If`の中に`If`)はサポートされていません。内側の`If`の行は無視され、
  内側の`EndIf`で**外側の`If`が閉じられます**(それ以降の行は条件に関係なく
  実行されます)。複数の条件を組み合わせたい場合は、`&&`・`||`を使って1つの
  条件式にまとめてください(例: `If = locked && wpn_ammo > 0`)。

### サブスクリプトの呼び出し(`Call` / `Exit`)

```
Call = compass_tape
```

`Call = スクリプト名`(拡張子・パス無し、小文字)で、同じ`hud`フォルダ内の
別のスクリプトファイルを呼び出せます。`Exit`は、現在の(`Call`で呼ばれた
場合はその)スクリプトの実行をそこで打ち切ります。

呼び出し先のスクリプトが見つからない場合は、何も起きません(エラーにはなりません)。
また、実行中のスクリプトを自分自身から(または呼び出しの連鎖の中で)再び`Call`した
場合、その`Call`は無視されます。

### 式構文

以下の演算子が使えます(上ほど優先順位が低く、括弧`( )`で優先順位を変更できます)。

| 演算子 | 内容 |
|---|---|
| `条件 ? 値1 : 値2` | 三項演算子(条件が0以外なら値1、0なら値2) |
| `\|\|` | 論理和(どちらかが0以外なら1、それ以外は0) |
| `&&` | 論理積(両方が0以外なら1、それ以外は0) |
| `==` `!=` | 等しい / 等しくない(真なら1、偽なら0) |
| `>` `<` `>=` `<=` | 比較(真なら1、偽なら0) |
| `+` `-` | 加算 / 減算 |
| `*` `/` | 乗算 / 除算(0で割った場合は0) |
| `-` `!` | 符号反転 / 論理否定(単項演算子。`!`は0なら1、0以外なら0) |

- 数値は10進数(`12`・`0.5`)のほか、16進数(`#FF00FF`または`0xFF00FF`)でも
  記述できます。`Color`にパック済みARGB値を渡す場合などに便利です
  (例: `Color = #FF00FF00`)。
- 変数名は大文字・小文字を区別しません。存在しない変数名を書いた場合、
  **エラーにはならず0として扱われます**。綴りの間違いに注意してください。
- 三角関数等の関数呼び出しはサポートされていません(回転を伴う描画は、後述の
  `DrawTexture`自身が持つ回転パラメータを利用してください)。

例:
```
DrawString = 0, 0, "%03d", yaw < 0 ? yaw + 360 : yaw
If = lock_progress > 0 && !locked
```

変数名は下記「3. 変数一覧」を参照してください。

## 2. 描画コマンド一覧

すべての座標は画面中央(`center_x, center_y`)を原点とした相対座標です。

### `Color`
- **書式**: `Color = パック済みARGB整数` または `Color = a, r, g, b`
- **説明**: 以降の描画コマンドで使う色を設定します。

### `DrawString` / `DrawCenteredString`
- **書式**: `DrawString = x, y, "書式文字列", 値1, 値2, ...`
- **説明**: printf風の書式文字列でテキストを描画します。`%d`(整数)・`%.Nf`
  (小数)・`%s`(文字列。バインドされた文字列変数名をそのまま渡すと、その
  値に置換されます。後述の`wpn_name`等)に対応しています。`DrawCenteredString`
  は水平方向中央揃えで描画します。

### `DrawTexture`
- **書式**: `DrawTexture = "テクスチャ名", x, y, w, h, u, v, uw, vh, 回転角度(度、Optional)`
- **説明**: `assets/<namespace>/textures/gui/<テクスチャ名>.png`(または
  読み込み済みの他アドオンのテクスチャ)から、`(u,v)`を左上とする
  `uw×vh`ピクセルの矩形領域を切り出し、`(x,y)`を左上として`w×h`の
  大きさで描画します。最後の回転角度(度数、Optional)を指定すると、
  描画領域の中心を軸に時計回りへ回転させます。回転を伴う針・インジケーター
  類の描画に、三角関数を使わず直接利用できます。
- **例**: `DrawTexture = "needle", -8, -8, 16, 16, 0, 0, 16, 16, gun_yaw`

### `DrawRect`
- **書式**: `DrawRect = x, y, w, h`
- **説明**: 塗りつぶし矩形を描画します。w・hに負の値を渡すと、その方向へ
  伸びるバー(残量表示等)として使えます。

### `DrawLine` / `DrawLineStipple`
- **書式**: `DrawLine = x1, y1, x2, y2, x3, y3, ...`
- **説明**: 連続する2点ずつを結ぶ線分を描画します(3点以上でつながった
  折れ線も可能)。`DrawLineStipple`は先頭2つの引数(破線パターン・
  間隔)を追加で取りますが、破線表現自体は未対応で通常の実線として
  描画されます。

### `DrawGraduationYaw`
- **書式**: `DrawGraduationYaw = 中心角度, x, y`
- **説明**: 画面上部を横切るコンパステープ(方位目盛り)を描画します。

### `DrawGraduationPitch1`
- **書式**: `DrawGraduationPitch1 = 中心角度, x, y`
- **説明**: 画面側面のピッチ目盛り(はしご状)を描画します。

### `DrawGraduationPitch2`
- **書式**: `DrawGraduationPitch2 = ピッチ角度, ロール角度, x, y`
- **説明**: 画面中央の簡易アーティフィシャルホライズン(ピッチ・ロール
  両対応の水平線)を描画します。

### `DrawCameraRot`
- **書式**: `DrawCameraRot = x, y`
- **説明**: プレイヤー自身の視点が、車両本体の向きからどれだけ離れて
  いるか(`plyr_yaw - yaw`)を示す小さなマーカーを描画します。

### `DrawEntityRadar` / `DrawEnemyRadar`
- **説明**: 未実装です(記述してもエラーにはならず、単に何も描画され
  ません)。

| `width` / `height` | 画面全体のピクセルサイズ |
| `yaw` / `pitch` / `roll` | 車両本体の現在の向き(度) |
| `plyr_yaw` / `plyr_pitch` | 搭乗者自身の視点の向き(度、ワールド絶対値) |

| 変数名 | 内容 |
|---|---|

|---|---|
| `hp` / `max_hp` | 現在体力 / 最大体力 |

| `fuel` | 燃料の割合(0〜1) |
| `low_fuel` | 燃料低下時、点滅間隔で1と0を交互に返す |

### 操縦入力
| 変数名 | 内容 |
|---|---|
| `throttle` | 現在のスロットル値 |
| `stick_x` / `stick_y` | 操縦桿相当の入力値(-1〜1程度) |
| `free_look` | フリールックモード中か(0/1) |
| `manual_mode` | マニュアルモード中か(0/1。Aircraft/VTOLのみ意味を持つ) |
| `stalling` | 失速中か(0/1。Aircraft/VTOLのみ意味を持つ) |
| `gear_deployed` | 着陸装置が展開しているか(0/1) |

### 武装(選択中の武器について)
| 変数名 | 内容 |
|---|---|
| `wpn_name` | 選択中武器の表示名(文字列変数、`DrawString`の`%s`で使用) |
| `wpn_ammo` / `wpn_rm_ammo` | 現在の弾数 / 弾倉サイズ |
| `reloading` / `reload_time` | 装填中か(0/1) / 残りtick数(発射レートの遅延も含む) |
| `wpn_heat` / `is_heat_wpn` | 熱量の割合(0〜1) / 熱管理式武器か(0/1) |
| `lock_progress` / `locked` / `lock` | ロックオン進捗(0〜1) / ロック完了か(0/1) / `lock_progress`と同値 |
| `wpn_mode` / `has_modes` | 現在の武器モード番号 / 複数モードを持つか(0/1) |
| `sight_type` | 照準タイプ(内部の列挙値) |
| `mortar_distance` / `mortar_distance_str` / `has_mortar_distance` | 迫撃距離(数値/文字列) / 表示対象武器か(0/1) |
| `gun_yaw` / `gun_pitch` | 「4. 記載例」参照 |

### その他
| 変数名 | 内容 |
|---|---|
| `time` | ワールドの時刻(0〜23999) |

## 4. 記載例: 砲塔向きインジケーター

### `gun_yaw` / `gun_pitch`

現在選択中の武器(`wpn_ammo`等と同じ、クライアント側で選択中の武器)が
**実際に現在向いている方向**を表す変数です。車両本体の向き(`yaw`)を
基準とした相対角度(度)で、`gun_yaw`が0であれば車両の正面、負であれば
左、正であれば右を指します。

`plyr_yaw`(搭乗者自身の視点)とは異なり、この値は`turret_rotation_speed`
(`Readme_Vehicle.md`4章参照)による旋回速度制限を考慮した、**実際に
弾丸が発射される方向**をそのまま反映します。速度制限のある武装では、
搭乗者が視点を素早く動かしても、`gun_yaw`はその制限速度でしか変化
しません。速度制限のない武装(`turret_rotation_speed`未設定)では、
搭乗者の視点へ即座に追従します。武器を切り替えた際は、切り替え後の
武器自身の設定(速度制限の有無・値)が即座に反映されます。

`turret_rotation_speed`が設定されていない武器を選択している間は、常に
搭乗者自身の視点方向と一致します。`aim_range`(照準範囲)自体が設定
されていない固定武装を選択している間は、`gun_yaw`・`gun_pitch`ともに
`0`を返します(方向という概念自体を持たないため)。

### 記載例1: 回転する針テクスチャ

```
; 中心(0,0)を軸に、選択中武器の実際の向きへ回転する砲塔インジケーター針。
; テクスチャは16x16pxで、針の根元が画像中心に来るよう用意してください。
DrawTexture = "turret_needle", -8, -8, 16, 16, 0, 0, 16, 16, gun_yaw
```

### 記載例2: 線分による簡易インジケーター

テクスチャを用意しない場合、`DrawLine`と`DrawCameraRot`と同じ考え方
(角度をピクセルオフセットへ変換)で、簡易的な水平バーとしても表示
できます。

```
; 画面下部中央に、車両正面(0度)を中心とした±60度のコンパスバー。
; 選択中武器が現在向いている角度に、白いマーカーを表示する。
Color = 255, 255, 255, 255
DrawLine = -60, 100, 60, 100
DrawRect = gun_yaw - 1, 96, 2, 8
```

### 記載例3: 数値表示

```
DrawString = 0, 110, "GUN: %.0f", gun_yaw
```
