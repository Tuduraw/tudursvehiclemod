# FictionalWW2Pack（Tudur's Vehicle Mod 用 拡張パック）

架空のWW2機20機を収録した、Tudur's Vehicle Mod（Minecraft 1.21.11 / Fabric）用のアドオンパックです。

## 導入方法

このフォルダ（`FictionalWW2Pack`）を圧縮せずにそのまま、次の場所へコピーします。

```
<ゲームディレクトリ>/tudursvehiclemod-addons/FictionalWW2Pack/
```

ゲーム内で `/reload` を実行するか、ゲームを起動すると読み込まれます。
機体はMOD本体の航空機スポナーに表示されます（ティア1〜5）。表示名は「名前 (勢力)」です。

- 名前空間: `ww2fict`
- 機体ID: `ww2fict:a_fighter` など

## 収録内容

| 種類 | 場所 |
|---|---|
| 機体定義 | `data/ww2fict/vehicles/*.json`（20機） |
| モデル | `assets/ww2fict/models/obj/*.obj`（+X=左、+Y=上、+Z=前、1ブロック=1m。可動部は `$` で始まるグループ） |
| テクスチャ | `assets/ww2fict/textures/vehicle/*.png`（512×512。ガラスは半透明） |
| 武器 | `assets/ww2fict/weapons/*.txt`（9種） |
| 弾体モデル | `bullet_tracer` / `bullet_bomb250` / `bullet_bomb500` / `bullet_torpedo` |
| 効果音 | `assets/ww2fict/sounds/*.ogg`（エンジン・機銃・機関砲・投下。合成音） |

## 可動部の動き

- **プロペラ**: 常時回転します。
- **キャノピー**: Hキーで開閉します。召喚時は開いた状態です。
- **引込脚**: 降着装置キーで動きます。ギアドア・車輪も一緒に動きます。
- **フラップ・着艦フック**: 脚を出すと下がります。
- **主翼折り畳み（艦上機）**: 主翼折り畳みキーで動きます。
- **爆弾倉扉・ダイブブレーキ**: 爆弾や魚雷を選んでいる間だけ開きます。
- **爆弾・魚雷**: 投下すると1発ずつ消えます（`ammo_parts`）。
- **旋回銃座**: 砲塔は銃手の視点に合わせて旋回し、銃身は上下に動きます。
- **エルロン・方向舵（A/Dキー）**: `steering_wheel_parts` で左右入力に連動します。Aキー（左）では左エルロンが上がり、右エルロンが下がり、方向舵は左へ振れます。
- **尾輪・固定脚の車輪（A/Dキー・走行）**: `wheel_parts` で地上走行中に回転し、尾輪は方向舵と同じ向きに首を振ります。

補足:

- **地上姿勢**: 尾輪式の機体は `on_ground_pitch` で機首上げの姿勢になります。
- **見た目だけの連動**: エルロン・方向舵は実際の飛行挙動とは連動せず、左右入力に合わせて見た目だけが動きます（地上でも同じように動きます）。
- **動かない部分**:
  - 昇降舵: MOD本体の機首上げ下げが視点追従のため、連動できる入力がありません。
  - 主翼折り畳み機（艦上戦闘機・艦攻・艦爆）のエルロン: 外翼と一緒に折り畳む必要があるため固定です。
  - 引込脚の車輪: 脚の開閉アニメーションと両立できないため回転しません。
  - 爆弾投下アーム: 固定です。
- **調整**: 性能値（速度・旋回性・耐久・燃料）や座席位置は、JSONや武器txtを編集して `/reload` すれば反映されます。

## 再生成

`Aircraft/_kit/mod_export.py` を使うと、Blender の各機体から OBJ と JSON を再出力できます。
