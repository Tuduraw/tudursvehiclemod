# Readme_Weapon_Torpedo.md - 魚雷(`Torpedo`)特有の項目

`Readme_Weapon.md`の共通項目に加え、`Type = Torpedo`でのみ意味を持つ項目です。

---

## 発射制限

- 機体の姿勢がほぼ水平(ピッチ・ロールいずれも±15度以内)、かつ低高度
  (直下の地面/水面までの距離が`TorpedoMaxAltitude`以下。既定40ブロック)
  でなければ使用できません
- 潜水艦(`Readme_Vehicle_Submarine.md`参照)は、潜航中(ハッチ閉)でも
  この武器タイプのみ使用できます

---

## 挙動

発射直後は機体の速度を引き継ぎ、`Gravity`に従って落下します。**着水した瞬間から
専用の水中巡航フェーズに切り替わり**、以降は`Gravity`の影響を受けなくなります。
水中では、着水時の角度から徐々に水平へ戻りながら、`TargetDepth`の深度で航走します
(`GuidedTorpedo`の設定にかかわらず、すべての魚雷で同じです)。

**例**:
```
DisplayName = Type.93 Torpedo
Type = Torpedo
Power = 200
Gravity = -0.03
AccelerationInWater = 2.5
VelocityInWater = 0.3
TargetDepth = 3.0
GuidedTorpedo = true
Explosion = 6
ExplosionInWater = 12
Round = 3
```

## `AccelerationInWater`
- **書式**: 数値(既定値: `4.0`)
- **説明**: 水中巡航時の目標速度。着水直後からこの速度まで徐々に加速します。
- **例**: `AccelerationInWater = 2.5`

## `VelocityInWater`
- **書式**: 数値(既定値: `0.5`)
- **説明**: 水中での速度変化の応答速度(tickごとにこの割合で目標速度へ近づくイージング係数)。
- **例**: `VelocityInWater = 0.3`

## `TargetDepth`
- **書式**: 数値(既定値: `2.0`)
- **説明**: 本プロジェクト独自の追加項目(MCヘリ非対応)。水面からこのブロック数だけ下を目標巡航深度とします(`水面Y - TargetDepth`)。
- **例**: `TargetDepth = 3.0`

## `GuidedTorpedo`
- **書式**: 真偽値(既定値: `false`)
- **説明**: 水中での水平方向の誘導の有無です。深度の維持(`TargetDepth`)は、
  この設定にかかわらず行われます。
  - `false`(既定): 無誘導魚雷です。着水したときの進行方向へまっすぐ進みます
  - `true`: 誘導魚雷です。誘導の方式は、ロックモード(既定は**Bキー**で切替。
    僚機への指示と同じキーです)で切り替えます
    - ロックモードがオフ: 発射時の照準地点(視線の先の地点)へ向かって進みます。
      その地点の3ブロック以内まで近づいたら、以降はまっすぐ進みます
    - ロックモードがオン: この武器を選択している間、視線の先(視線から15度以内、
      最大1000ブロック)にいる最も視線に近いエンティティが強調表示されます。
      発射すると、そのエンティティを追跡します(ミサイルのロックオンと同様です)。
      強調表示されているエンティティがいない場合は発射できません
  - 旋回の速さは`TurnRate`(1tickあたりの角度)で指定します。0以下の場合は
    2度/tickです
  - どちらの方式でも、目標を追い越した(近距離で目標が後方になった)場合は、
    引き返さずにそのまままっすぐ進みます(目標の周りを回り続けないためです)
  - AI(僚機・Carrierの艦載機・ダミーパイロット)が発射した場合は、そのAIが攻撃している
    目標を追跡します(ロックモードの設定とは関係ありません)
- **例**: `GuidedTorpedo = true`

## `TorpedoMaxAltitude`
- **書式**: 数値、単位はブロック(既定値: `40`)
- **説明**: 魚雷を発射(投下)できる最大の高度です。機体の直下にある地面または
  水面からの高さで判定し、これより高い位置からは発射できません。以前は15ブロックで
  固定されていました。
- **例**: `TorpedoMaxAltitude = 30`

## `GravityInWater`
- **書式**: 数値(既定値: 通常の`Gravity`と同値)
- **説明**: 水中に入るまでの落下速度とは別の、水没後専用の落下速度(`Readme_Weapon.md`の共通項目としても使用できますが、魚雷では特に意味を持ちます)。
- **例**: `GravityInWater = 0.0`
