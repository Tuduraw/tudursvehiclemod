# Readme_AddTexture.md - ダミーパイロットのスキン追加方法

DroneCenterで使うダミーパイロットの見た目(スキン)を、新たに追加するための
アドオンパックの作り方をまとめたものです。コードの変更・再ビルドは一切
不要です。乗り物・武器のアドオン(`Readme_Addon.md`参照)とは別の、
独立した仕組みです。

---

## 1. 配置場所

`Readme_Addon.md`の「1. 配置場所」と同じです。最も簡単な方法は、

```
<ゲームディレクトリ>/tudursvehiclemod-addons/<任意のアドオン名>/
```

に、圧縮せずそのままのフォルダ構造で配置することです(方法A・推奨)。
通常のリソースパックとして配置する方法(方法B)にも対応しています。

---

## 2. ディレクトリ構造

```
tudursvehiclemod-addons/
└── <アドオン名>/
    └── textures/
        └── dummy_pilot/
            └── <スキンID>.png      … ダミーパイロットのスキン画像
```

乗り物アドオンの`assets/<namespace>/`という構造とは異なり、この
`textures/dummy_pilot/`は**名前空間を挟まない**、アドオンフォルダ直下の
パスである点に注意してください。

---

## 3. スキン画像の仕様

- **形式**: 通常のプレイヤースキンと同じ、64×64ピクセルのPNG形式
  (Minecraft 1.8以降の標準的なスキンレイアウトに対応しており、帽子・
  上着・袖・ズボンのオーバーレイ層も正しく表示されます)
- **ファイル名**がそのまま、ゲーム内で選択する際の**スキンID**になります
  (拡張子`.png`を除いた部分)
- スキンIDに使える文字は、半角英小文字・数字・アンダースコア(`_`)・
  ハイフン(`-`)・ピリオド(`.`)のみです。それ以外の文字(大文字・
  日本語・空白等)を含むファイル名は無視されます
- 本体が既に用意しているスキンID(`default`・`driver`・`soldier`・
  `ww2_pilot`)と同じ名前を付けると、**本体側が優先され、アドオン側の
  ファイルは無視されます**。独自のスキンには、他と被らない名前を
  付けてください

---

## 4. ゲーム内での選択方法

1. DroneCenterブロックを右クリックして設定画面を開きます
2. スキン選択欄の「<」「>」ボタンで、利用可能な全スキン(本体標準の
   4種類＋読み込まれた全アドオンのスキン)を順番に切り替えられます
3. 選択したスキンIDはDroneCenterのデータとして保存され、そのDrone
   Centerが管理するダミーパイロットに反映されます

---

## 5. リロード

- ゲーム内から`/reload`コマンドを実行すると、追加・変更したスキン
  ファイルが再スキャンされます。ゲームやワールドの再起動は不要です
- 既に選択済みのスキンIDが、アドオンの削除等により利用できなくなった
  場合は、自動的に本体標準の`default`スキンへ切り替わります(データが
  壊れたり読み込みに失敗したりすることはありません)

---

## 6. 補足: 本体標準スキンとの違い

本体が標準で用意している4種類のスキンのうち、`default`のみは特別で、
Minecraft本体が実際に内蔵しているSteveのテクスチャをそのまま参照して
おり、本体・アドオンのいずれにも画像ファイルとして存在しません。
アドオンとして追加するスキンは、通常のPNGファイルとして用意して
ください(この`default`のような特別な参照方式には対応していません)。
