# Readme_Addon.md - アドオンパックの配置方法

本MODで新しい乗り物・武器を追加するための、アドオンパックのディレクトリ構造・
必要なファイル・命名規則をまとめたものです。コードの変更・再ビルドは一切
不要です。

なお、アドオンパック作成に役立つエディタを用意しています(https://github.com/Tuduraw/TudursVehicle_AddonPackEditor)。

> **重要**: パックに含めるモデル・テクスチャ・音声について、他者が権利を
> 有するデータの取り扱いは`GUIDELINES.md`を必ず確認してください。

---

## 1. 配置場所

アドオンパックは、以下のいずれかの方法で配置できます。

### 方法A: 専用アドオンフォルダ(推奨)

```
<ゲームディレクトリ>/tudursvehiclemod-addons/<任意のアドオン名>/
```

に、**圧縮せずそのままのフォルダ構造**で配置します。`<任意のアドオン名>`は
好きな名前を付けられます(複数のアドオンを共存させる場合、それぞれ別名の
サブフォルダにします)。このフォルダはMOD初回起動時に自動的に作成されます。

### 方法B: 通常のリソースパック/データパック

上記と同じ内部構造を、Minecraft標準の`resourcepacks`フォルダ(`assets/`側)・
ワールドの`datapacks`フォルダまたは`resourcepacks`(`data/`側)へ、通常の
リソースパック・データパックとして配置することもできます。この場合、
Minecraft本体のリソースパック有効化操作が必要です。

**アドオンフォルダ(方法A)であれば、有効化操作は不要で、フォルダに配置する
だけで自動的に読み込まれます。**

---

## 2. ディレクトリ構造

```
tudursvehiclemod-addons/
└── <アドオン名>/
    ├── data/
    │   └── <namespace>/
    │       └── vehicles/
    │           └── <機体名>.json          … 機体定義(JSON)
    └── assets/
        └── <namespace>/
            ├── weapons/
            │   └── <武器名>.txt            … 武器設定(Key=Value形式)
            ├── models/
            │   └── obj/
            │       └── <機体名>.obj        … 3Dモデル(慣例上のパス)
            ├── textures/
            │   ├── vehicle/
            │   │   └── <機体名>.png        … 機体テクスチャ(慣例上のパス)
            │   └── gui/
            │       └── <画像名>.png        … HUD用テクスチャ
            ├── hud/
            │   └── <HUD名>.txt             … HUDスクリプト
            ├── sound/ または sounds/
            │   └── <音声名>.ogg            … 効果音・エンジン音
            └── lang/
                └── <言語コード>.json       … 翻訳(任意、バニラ標準形式)
```

`<namespace>`は任意の名前空間(英数字・アンダースコアのみ、慣例上
小文字。本MOD自体は`tudursvehiclemod`を使用しています)。複数のアドオンが
同じ名前空間を使うことも可能ですが、ファイル名が衝突すると後から読み込まれた
方で上書きされるため、独自のアドオンには専用の名前空間を使うことを推奨します。

---

## 3. 各ファイルの役割

### 機体定義(`data/<namespace>/vehicles/*.json`)

1機体につき1つのJSONファイル。ファイル名(拡張子なし)がそのままこの機体の
識別ID(`<namespace>:<ファイル名>`、サブフォルダを作った場合は
`<namespace>:<サブフォルダ>/<ファイル名>`)になります。項目の詳細は
`Readme_Vehicle.md`・`Readme_Vehicle_○○.md`を参照してください。

### 武器設定(`assets/<namespace>/weapons/*.txt`)

1武器につき1つのテキストファイル。ファイル名(拡張子なし、大文字小文字を
区別しない)が、機体JSONの`weapons`配列内`weapon_name`から参照されます。
項目の詳細は`Readme_Weapon.md`・`Readme_Weapon_○○.md`を参照してください。

### モデル(`assets/<namespace>/models/...`)

OBJ形式(三角形・四角形・多角形いずれも可)。パスは機体JSONの`model`項目で
自由に指定できますが、慣例上`models/obj/<名前>.obj`に配置します。

### テクスチャ(`assets/<namespace>/textures/...`)

PNG形式。パスは機体JSONの`texture`項目・武器の`ModelBullet`関連設定で自由に
指定できますが、慣例上`textures/vehicle/<名前>.png`に配置します。武器の
`ModelBullet`を設定した場合、対応するテクスチャは自動的に
`textures/vehicle/bullet_<ModelBulletの値>.png`が参照されます
(`Readme_Weapon.md`参照)。

### サウンド(`assets/<namespace>/sound/`または`sounds/`)

OGG形式(`.ogg`)。**フォルダ名は単数形`sound`・複数形`sounds`のどちらでも
認識されます**(サブフォルダに分けても構いません)。ファイル名(拡張子なし、
大文字小文字を区別しない)が、機体JSONの`engine_sound`・武器の`Sound`項目
から参照されます。**バニラの`sounds.json`は不要です**(本MODは独自の音声
読み込み機構を使用しており、`.ogg`ファイルさえ配置すればファイル名だけで
即座に参照可能になります)。

### HUDスクリプト(`assets/<namespace>/hud/*.txt`)

MCヘリ形式のHUD描画スクリプト。ファイル名(拡張子なし)が、機体JSONの`hud`
項目から参照されます。書式の詳細は同梱の`Readme_HUD.txt`を参照してください。

### HUD用テクスチャ(`assets/<namespace>/textures/gui/*.png`)

HUDスクリプトの`DrawTexture`命令から、ファイル名(拡張子なし)で参照される
画像。256×256推奨。

### 翻訳(`assets/<namespace>/lang/*.json`)

Minecraft標準のリソースパック言語ファイル形式。本MOD独自のキーは特にありません
(機体・武器の表示名はJSON/txtファイル自身の`display_name`/`DisplayName`項目に
直接記述する形式のため)。

## 4. 命名規則のまとめ

| 項目 | 大文字小文字 | 拡張子の扱い |
|---|---|---|
| 機体ファイル名(`vehicles/*.json`) | 区別する(識別IDに使われる) | 参照時は不要 |
| 武器ファイル名(`weapons/*.txt`) | **区別しない** | 参照時は不要 |
| サウンドファイル名(`sound(s)/*.ogg`) | **区別しない** | 参照時は不要 |
| HUDスクリプトファイル名(`hud/*.txt`) | 区別する | 参照時は不要 |
| 名前空間(`<namespace>`) | 慣例上小文字 | — |

機体JSON内の各種キー(`entity_type`・`model`等)は全て`snake_case`、武器
設定ファイル内のキー(`DisplayName`・`Type`等)は全て大文字小文字を区別
しません(慣例上MCヘリ由来の`PascalCase`表記を使用)。

---

## 5. リロード

- ゲーム内から`/reload`コマンドを実行すると、機体・武器・HUD・モデル・
  テクスチャ・サウンドの全てが再読み込みされます。ゲームやワールドの
  再起動は不要です
- 搭乗中に機体メニュー(Rキー) → MOD Option → Development からも、武器・
  HUDそれぞれ単体でのリロードが可能です
- 既にスポーン済みの機体エンティティは、機体定義自体の変更(座標・見た目等)
  については再スポーンしないと反映されない場合があります。武器設定ファイル
  (`weapons/*.txt`)の数値調整は、既存の機体に乗ったままでも即座に反映されます

---

## 6. 既存のMCヘリアドオンからの変換

既にMCヘリ用のアドオンパックをお持ちの場合、同梱の変換ツール
(`tools/mcheli_convert.py`または`tools/mcheli_convert_gui.py`)で、上記の
ディレクトリ構造へ自動変換できます。詳細は`GUIDE.md`の「MCヘリアドオンの
変換方法」セクションを参照してください。変換後の出力フォルダを、そのまま
`tudursvehiclemod-addons/`配下に配置すれば利用できます。

> **重要**: MCヘリ向けに公開されている拡張パックは、その作者がMCヘリ以外での
> 利用を明示的に許可している場合を除き、このMODでは使用できません。変換機能が
> 技術的に動作することと、それが許諾されていることは別問題です。詳細は
> `GUIDELINES.md`を参照してください。
